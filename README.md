# Equation solver

Can solve any type of system of linear equations.
For system of equations which have a unique solution, it gives out the values, and for system which has infinite
solutions, gives one of the basis of the solution space and dimension of the solution space.

## To run:

Build the Cmake file, and run the matrix executable.
Enter equations in natural language form, where the variables should be on the L.H.S. and the constant on R.H.S. .
The variables can have any name or number just like any variable name in c++.
Each equation should be terminated by a semicolon(;).
